クオンツ・金融志望。日本株の有価証券報告書を分析し、将棋AIやルービックキューブのアプリも開発しています。

GitHub WCA Profile Email

サマリー

  • 研究：日本株の約4,000社・26年分の有価証券報告書を対象に、非財務情報をOCRとLLMでスコア化しています。
  • 将棋AIの開発：ResUNetを用いて20億局面を学習した「芽生将棋」で世界コンピュータ将棋選手権に2年連続出場。2026年に一次予選37チーム中4位で二次予選に進出。
  • データ分析・モデリング：Python による時系列データの前処理・回帰分析。適切な手法を選び、学習・検証を完遂できます。
  • 金融知識：四季報や日経新聞の購読を日課とし、市場と経済への関心が高いです。

学歴・研究

  • 成蹊大学 経済学部 経済数理学科 3年（金融工学専攻）
  • ゼミ研究テーマ：LLMによる非財務情報のスコア化
  • 分析結果：人的資本の点数と翌年のROAの順位相関は r = 0.20（t = 24.9、約7万社年）。年・文章量・企業規模の影響を除いた後の値で、t値は企業ごとのまとまりを考慮しています。上場廃止企業2,185社を加えても、結果はほぼ変わりませんでした。

日本株シミュレーション

金融工学 MCMC / CAPM
説明を読む

マルコフ連鎖モンテカルロ法（MCMC）による日経平均の予測と、その推定値を用いたCAPM理論に基づく個別株リターン予想。さらにFama-Frenchの3ファクターモデルを用いて、日本株が各因子をどれほど持っているかをプロットしました。
